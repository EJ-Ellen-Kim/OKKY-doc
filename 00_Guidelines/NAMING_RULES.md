# NAMING_RULES

## Korean
- 상위 메뉴는 영문 단어 **첫 글자 대문자** 사용 (예: QNA, Knowledge, Community)
- 하위 메뉴는 **[상위메뉴명]_[영문명]** (예: Knowledge_Tips, Community_Life)
- 한글 복합어는 **CamelCase** 변환 (예: JobSeekers, CompanyReview, BoardRequest)

## English
- Top-level menus use English words with the **first letter capitalized** (e.g., QNA, Knowledge, Community).
- Sub-menus follow the consistent format **[ParentMenuName]_[EnglishName]** (e.g., Knowledge_Tips, Community_Life).
- When a Korean menu name consists of multiple words, convert to **CamelCase** (e.g., JobSeekers, CompanyReview, BoardRequest).

## File & Folder Naming
- Documents: `PascalCase` + underscores (e.g., `Menu_Hierarchy_Code.md`)
- Folders: numeric prefix for ordering (e.g., `00_Guidelines`, `01_Current_State`)
- Abbreviations remain uppercase: `QNA`, `IT`, `AI`
