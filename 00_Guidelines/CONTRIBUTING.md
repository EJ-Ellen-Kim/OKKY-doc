# CONTRIBUTING

Thank you for contributing to the OKKY Spec docs.

## Process
1. Open an **Issue** describing the change or proposal.
2. Create a `feature/<short-topic>` branch.
3. Update docs and templates as needed.
4. Open a **Pull Request** and request reviews from PM/UX/Policy/Operations.
5. On merge: ensure **CHANGELOG.md** and **DECISION_LOG.md** updated if relevant.

## Style
- Keep documents concise with clear headings.
- Each doc should start with **front matter**:
```
---
title: <Doc Title>
version: 1.0
author: <name>
updated: 2025-10-24
status: draft
---
```
- Use **English file names** with PascalCase and underscores as in examples.
